Política de Privacidade

Esta secção explica que dados recolhemos através do website, por que razão os recolhemos, quais os serviços terceiros envolvidos e como os tratamos.

Quem somos

A Lumen and Pixel é um estúdio de produção de eventos ao vivo baseado em Portugal. Este website é utilizado para apresentar os nossos serviços, recolher pedidos de orçamento e permitir que os visitantes subscrevam a nossa newsletter.

O que recolhemos

  • Submissões do formulário de contacto, incluindo nome, empresa ou organização, endereço de email, serviço selecionado e mensagem do projeto.
  • Subscrições de newsletter: o seu endereço de email, a data e hora da subscrição e o texto exato do consentimento que aceitou.
  • Informação técnica básica necessária para a entrega do website, como o endereço IP registado nos registos de servidor do nosso alojamento.

Por que razão utilizamos os dados

  • Para responder a pedidos de projeto e outras mensagens enviadas através do website.
  • Para enviar atualizações da newsletter a utilizadores que subscreveram explicitamente.
  • Para entregar recursos ou redirecionar visitantes para páginas de compra externas quando relevante.

Bases legais

  • Os pedidos de projeto são tratados com base no interesse legítimo, para que possamos responder aos pedidos recebidos.
  • As subscrições de newsletter são tratadas com base no consentimento.
  • Quando as compras são realizadas através do Gumroad, os dados de pagamento e checkout são geridos pelo Gumroad ao abrigo dos seus próprios termos e práticas de privacidade.

Serviços terceiros utilizados neste website

Nenhum código de terceiros é executado no seu navegador neste website. As fontes são servidas a partir deste domínio e não existe qualquer script de analítica, publicidade, rastreio ou marketing incorporado em nenhuma página. Os serviços abaixo são utilizados, mas o seu navegador só os contacta se submeter um formulário ou seguir uma ligação para eles.

  • GitHub Pages — aloja este website. Os pedidos, incluindo endereços IP, são tratados pelo GitHub para entregar as páginas.
  • n8n Cloud — recebe as submissões do formulário de contacto e as subscrições de newsletter no momento em que as envia, encaminhando-as para nós.
  • cal.com — apenas se optar por agendar uma chamada. O agendamento decorre no site deles, ao abrigo dos seus próprios termos.
  • Gumroad — apenas se seguir uma ligação para a nossa loja. As compras e os dados de pagamento e checkout são tratados inteiramente pelo Gumroad, ao abrigo dos seus próprios termos.

Quanto tempo guardamos os dados

Guardamos os dados de pedidos e newsletter apenas pelo tempo razoavelmente necessário para comunicação, acompanhamento operacional ou fins legais e administrativos.

Os seus direitos

Pode solicitar o acesso, correção ou eliminação dos seus dados pessoais, ou opor-se a certos tipos de tratamento, conforme aplicável ao abrigo da legislação relevante. Os emails da newsletter incluem também uma opção de cancelamento de subscrição.

Como nos contactar

Para pedidos relacionados com privacidade, utilize o formulário de contacto na página Sobre.

Cookies

Este website não define quaisquer cookies próprios e não carrega código de terceiros no seu navegador.

  • Não é utilizada qualquer analítica, publicidade ou rastreio neste website.
  • Não definimos quaisquer cookies e não é necessário um aviso de consentimento, porque não há nada a consentir.
  • As fontes são servidas a partir deste domínio e não de um serviço externo, pelo que carregar uma página não revela o seu endereço IP a terceiros.
  • O nosso alojamento regista informação padrão de servidor para poder entregar o site. Submeter um formulário ou seguir uma ligação externa contacta o serviço correspondente indicado na Política de Privacidade acima.
  • Se alguma vez for adicionado rastreio não essencial, esta secção será atualizada e o consentimento será pedido antes do seu carregamento.
